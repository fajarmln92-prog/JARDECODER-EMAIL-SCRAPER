☠️ JARDECODER EMAIL SCRAPER </>
WEBSITE CONTACT EMAIL DISCOVERY TOOL

JARDECODER EMAIL SCRAPER is a Python-based tool designed to discover publicly listed email addresses on authorized websites.

✨ FEATURES
🌐 Website Email Discovery
🔎 Email Pattern Detection
🔗 Same-Domain Link Crawling
📄 Custom Page Limit
♻️ Duplicate Email Filtering
💾 Automatic TXT Report Saving
🎨 Terminal Interface
📱 Termux Support
🐉 Kali Linux Support
📱 SUPPORTED PLATFORMS
Android (Termux)
Kali Linux
Debian / Ubuntu
📦 REQUIREMENTS
Python 3
Git
Internet Connection
Requests
BeautifulSoup4
Chafa (Optional)
🚀 INSTALLATION
1. TERMUX (ANDROID)

Update packages:

bash
pkg update && pkg upgrade -y


Install dependencies:

bash
pkg install python git chafa -y


Clone repository:

bash
git clone https://github.com/USERNAME/JARDECODER-EMAIL.git


Enter directory:

bash
cd JARDECODER-EMAIL


Install Python libraries:

bash
pip install -r requirements.txt


Run the script:

bash
python email_scraper.py

2. KALI LINUX

Update packages:

bash
sudo apt update


Install dependencies:

bash
sudo apt install python3 python3-venv git chafa -y


Clone repository:

bash
git clone https://github.com/USERNAME/JARDECODER-EMAIL.git


Enter directory:

bash
cd JARDECODER-EMAIL


Create virtual environment:

bash
python3 -m venv .venv


Install requirements:

bash
.venv/bin/pip install -r requirements.txt


Run the script:

bash
.venv/bin/python email_scraper.py

Reports are automatically saved to:

text
